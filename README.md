# 🎬 Netflix Data Analytics Dashboard using Power BI

## 📌 Project Overview

This project is a **Netflix Data Analytics Dashboard** created using **Microsoft Power BI**. The dashboard provides insights into Netflix content such as movies and TV shows by analyzing genres, countries, ratings, release years, and content trends.

The objective of this project is to transform raw Netflix dataset information into meaningful visual insights using interactive dashboards and data visualization techniques.

---

## 🚀 Features

* 📊 Interactive Power BI Dashboard
* 🎥 Movies vs TV Shows Analysis
* 🌍 Country-wise Content Distribution
* 🎭 Genre Analysis
* ⭐ Ratings Classification
* 📅 Release Year Trends
* 🔎 Filter and Drill-down Functionality
* 📈 Data-driven Visual Insights

---

## 🛠️ Technologies Used

* **Microsoft Power BI**
* **Microsoft Excel / CSV Dataset**
* **DAX (Data Analysis Expressions)**
* **Data Visualization Techniques**


## 📊 Dashboard Insights

The dashboard helps users understand:

* Which genres are most popular on Netflix
* Which countries produce the highest amount of content
* Growth of Netflix content over the years
* Distribution of ratings across movies and TV shows
* Comparison between Movies and TV Shows
